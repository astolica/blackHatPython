# Black Hat Python: My Notes and Enhanced Tools

My working repo for *Black Hat Python, 2nd Edition*. For each chapter, I
build the tool from the book, rebuild it from memory, and then write an
enhanced version with my own improvements (error handling, argparse, logging,
and so on).

## Goals

- Understand how offensive tooling works with Python 
- Learn how these tools look from a defender's side if possible (logs, network traffic)
- Build skills toward red teaming overall
